铸造前，先了解这些

什么时候开放交易？

铸造阶段（未开盘）代币不可转移；当总份数达到上限（打满）后，合约自动开盘、开放交易。

3% 税里的“销毁”会减少总量吗？

不会。销毁部分转入黑洞地址 0x000…dEaD，但代币总供应量固定，黑洞余额增加不改变上限。

没有币安 Agent ID 能铸造吗？

不能。铸造入口会校验你的地址是否持有币安 Agent ID NFT，未持有将被 revert。
