用币安 AI 钱包（Agentic Wallet）铸造

  • 本页填地址 → 选份数 → 点「生成 AI 指令」，指令会自动复制。
  • 把指令发给你自己的 AI 代理（需已安装币安 Agentic Wallet 的 baw CLI 并开启 devMode）。
  • 代理会用你的 AI 钱包完成 approve + mint，每笔都会先 preview 并等你确认。

Agentic Wallet 是给 AI 代理用的钱包，没有网页连接接口，所以本页无法直接连接它 —— 与 jager.live 的做法一致：网页生成指令，AI 代理执行铸造。

让 AI 代理帮你铸造

01

开启开发者模式

在币安 App 中，为你的 Agentic Wallet 开启开发者模式。

Agentic Wallet → 设置 → 开发者模式

02

检查资格

在上方铸造区输入你的 .ai 名称。这个地址需要有：

  • Agent ID
  • 每次 0.01 USDT
  • 少量 BNB 付手续费
03

发给你的 AI 代理

把指令粘贴到 Agentic Wallet 的 AI 对话里。每一步它都会先预览，等你确认后再执行。

如何申请 Agent ID

专属邀请链接 web3.binance.com/agent-id/aveai?src=user_share
去注册
01

打开邀请链接

用币安 App 扫码，或在币安 Web3 钱包内置浏览器打开，进入 Agent ID 页面。

02

连接 / 创建 Agentic Wallet

钱包里预留一点 BNB 付网络手续费。

03

选 .ai 名称并提交

按页面提示完成注册；是否仍需邀请名额，以官方页面显示为准。

04

回来检查资格

Agent ID 到账后，在上方铸造区填地址点「检查资格」，显示持有 ≥ 1 即可铸造。

注册流程与名额以币安官方页面为准，可能随时调整。
