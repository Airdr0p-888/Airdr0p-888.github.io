铸造前，先了解这些

什么时候开放交易？

铸造阶段（未开盘）代币不可转移；当总份数达到上限（打满）后，合约自动开盘、开放交易。

3% 税里的“销毁”会减少总量吗？

不会。销毁部分转入黑洞地址 0x000…dEaD，但代币总供应量固定，黑洞余额增加不改变上限。

V3 的 LP 去哪了？

V3 发射的 LP 直接发送到部署钱包（可在部署时或部署后由 owner 设置接收地址），不同于 V1 的锁黑洞。

没有币安 Agent ID 能铸造吗？

不能。铸造入口会校验你的地址是否持有币安 Agent ID NFT，未持有将被 revert。

币安 App 扫码登录

用币安 App 扫上方二维码，确认配对码一致后授权连接。
